Poker Game

Java • GUI Development • Game Logic • AI

Download PDF

Project Overview

This project is a 1v1 Texas Hold'em poker game developed in Java. I designed the application around a graphical user interface that allows the player to interact with the game through buttons for checking, calling, raising, and folding. Both players start with $1000, the blinds are $10 and $20, and the match ends when one player runs out of chips.

My Role

I served as the project manager and developer. I worked on the game's design and implementation, including the graphical interface, card system, betting mechanics, player management, and artificial intelligence opponent.

What I Built

Java Swing GUI
Poker Game Logic
AI Opponent
Betting System
Card Evaluation
Game State Management

Main Challenge

One of the more difficult parts of the project was creating the betting and AI decision-making system. The game had to keep track of player contributions, the pot, blinds, betting rounds, and whose turn it was. The dealer button also alternates every hand, which changes who posts the small blind and who acts first.

I also had to create logic that evaluates poker hands, including pairs, two pair, three of a kind, straights, flushes, full houses, four of a kind, straight flushes, and royal flushes. The AI uses the strength of its hand to decide whether to check, bet, call, raise, or fold, and it occasionally bluffs with a weak hand.

Technical Skills

Java
Object-Oriented Programming
Java Swing
Event Handling
Data Structures
Game Logic

Transferable Skills

Problem Solving
Project Management
Debugging
Organization
Critical Thinking
Persistence

What I Learned

This project helped me move beyond writing individual pieces of code and taught me how those pieces work together to create a complete application.

I gained experience designing a graphical interface, managing game states, creating decision-making logic, and debugging a larger Java application.

What I Would Improve

The AI's decisions are still fairly simple and can sometimes fold a strong hand, so the next step is tuning how it weighs hand strength against the size of a bet. I would also add better tie-breaking when both players have the same type of hand.

Self-Hosted Streaming Website

Java • Web Server • HTML • CSS

Download PDF

Project Overview

This project is a Netflix-style website that I hosted myself. Instead of using a web framework, I wrote a web server in Java that listens on port 8080 and sends back the pages directly. Visitors can move between a home page, a movies page, a TV shows page, and a "Who is watching?" profile screen.

My Role

I designed and built the whole site: the Java server, the page layouts, the dark theme, and the navigation between pages.

What I Built

Java Web Server
Four Linked Pages
Movie and Show Grids
Profile Selection Screen
Dark Streaming Theme
Hover Effects

Main Challenge

The biggest challenge was understanding how a web server actually works. Each page has its own handler, and the server has to match a web address such as /movies to the correct handler and send back a complete response.

I also had to keep the layout consistent across pages. I used CSS flexbox to line up the posters and profiles, and I kept the same navigation bar and color scheme on every page so the site feels like one application.

Technical Skills

Java
HTTP Requests and Responses
HTML
CSS Flexbox
Request Routing
Self-Hosting

Transferable Skills

Problem Solving
Troubleshooting
Attention to Detail
Independent Learning
Design Thinking
Persistence

What I Learned

This project showed me what happens between typing an address into a browser and seeing a page. I learned how a server receives a request, chooses a handler, and sends a response, and how HTML and CSS turn that response into something people can use.

Hosting the site myself also gave me hands-on experience with ports, network access, and testing a service from other devices.

How This Prepares Me for My Career

Web servers, requests, ports, and network access come up constantly in IT work. Building one from scratch gave me a working understanding of these ideas that I can apply to troubleshooting, supporting users, and learning new server technologies.

What I Would Improve

Right now the movie and show lists are written directly into each page, and the posters load from other websites. I would move the titles into a data file or database, host the images myself, and add real video playback and separate profiles.

SQL Server Project

SQL Server • T-SQL • Database Design

Download PDF

Project Overview

This project is a pet store database built in SQL Server. A single script creates a database called dbpetstore, builds two related tables, fills them with sample data, and then checks the results with a few queries.

My Role

I wrote the whole script myself, from creating the database and designing the tables to choosing the data types, setting up the keys, and adding the sample records.

What I Built

Database Creation Script
Pet Store Table
Pet Table
Primary and Foreign Keys
Cascading Updates and Deletes
Sample Data Inserts

Main Challenge

The hardest part was connecting the two tables correctly. Every pet has to belong to a store, so the pet table uses a foreign key that points back to the pet store table, and the stores have to exist before any pets can be added.

I also wanted the script to be re-runnable. It checks whether the database and tables already exist and removes them first, so I can run it again from a clean start every time.

Technical Skills

SQL Server
T-SQL
Table Design
Data Types and Constraints
Relational Databases
SELECT Queries

Transferable Skills

Problem Solving
Attention to Detail
Organization
Troubleshooting
Critical Thinking
Persistence

What I Learned

This project taught me how the tables in a database are tied together. I learned how primary keys and foreign keys keep the data consistent, and how cascading rules update or delete related records automatically.

I also practiced picking data types that fit the data, such as short codes for states and decimals for prices.

What I Would Improve

The database only has two tables right now. I would add tables for customers and sales, then write queries that join them together to answer questions like which store sells the most pets.

Project Overview

This project analyzes a video game sales data set in R. It is also a measurable checkpoint toward my final project. The main question is: what factors are associated with higher video game sales?

My Role

I wrote the R code, built the visualization, and wrote up the research question and the smaller questions that break it down.

What I Built

Sales by Genre
Sales by Platform
Platform and Genre Comparison
Regional Sales Reshaping
Faceted Scatter Plot
Written Analysis

Main Challenge

The biggest challenge was working with data that had to be grouped and reshaped before it could be compared. I had to total global sales by genre, by platform, and by both together, and then reshape the regional sales columns so the regions could be compared side by side.

I used AI to help me find the dplyr functions group_by() and summarise(), and to learn about pivot_longer() from the tidyverse.

This project showed me how a big question can be split into smaller questions that the data can actually answer. Each smaller question became its own grouped summary.

I also learned how much a clear chart helps, since the plot of sales by year, genre, and platform shows patterns that a table of numbers hides.

What I Would Improve

I would finish the regional comparison, write out what the results say, and look at more factors than genre and platform, such as the year a game was released.
